## [Unreleased]

### Fixed

- **Page width matches xfina.dev**: the content column is the full 72rem (1,152 px), with the padding outside it as xfina.dev has it. It was 64 px narrower because the padding was taken out of the column.

### Added

- **Unreadable documents, declared**: a dataset's `raw.unreadable` lists archived documents no parser can read, by sha256 and with a reason. They stay in the archive but are never downloaded for derivation; each skip is printed in the run log, and `metadata.json` lists them per dataset, so a missing period is explained rather than silent. The first entry is SBI's 2024-09-06 sheet (archived three times, as 09-06, 09-07 and 09-08), made with "Microsoft: Print To PDF" with its text turned into vector outlines: no fonts and no text, so it would need OCR.
- **Compressed downloads, documented**: the index's developer section shows fetching a CSV compressed, with `curl --compressed` and as raw HTTP headers. CSVs are served Brotli- or gzip-compressed on request through a Cloudflare compression rule, about a quarter of their plain size.
- **India CPI is published** at `v1/inflation/in-cpi.csv`: the all-India Combined general index, base 2024=100, monthly from 2013-01, from MoSPI's `Back` series up to 2024-12 and its `Current` series after. Values are exactly as MoSPI prints them (`55.10`, not `55.1`). Cross-checked against the predecessor's hand-made file: all 162 overlapping months agree.
- **Raw archive in R2**, served at `raw.data.xfina.dev`. Every source document is stored before anything is derived from it, written with `If-None-Match: *` so the bucket itself refuses an overwrite, with an explicit content type and an immutable one-year cache header. A key already holding different bytes gets a suffixed key instead; the original stays.
- **Raw manifests** at `v1/manifests/<id>.csv`: one row per archived document with its key, sha256, size, content type, fetch time, origin and source URL. Reads are checked against the recorded sha256.
- **`xfina-data sync`** fetches what is due, archives it, and for published datasets merges the new rows into the series, reporting every row added or changed. A dataset that fails does not stop the others, but the run fails at the end naming each one. Planned datasets are archived but not published.
- **`xfina-data backfill`** rebuilds a series from its archived documents alone, reading them from the public URL so it needs no credentials; `--check` fails if the published file differs.
- **`xfina-data raw import` and `raw put`** bring existing documents into the archive, recording where they came from. Re-running an import is safe.
- **SBI forex card source**: fetches the daily sheet, refuses a response that is not a PDF, and derives USD TT buy/sell through Xfina's published parser, dated by the sheet rather than the fetch. A sheet that does not parse fails the derivation by name; a sheet that quotes no USD rate yields no row and a note. The dataset stays `planned` until [xfina#91](https://github.com/xfina-dev/xfina/issues/91) lets every archived sheet parse.
- **USD/INR from the BIS is published** at `v1/fx/bis-usd-inr.csv`: rupees per US dollar each business day from 1973-01-02, 13,610 days. Days the BIS marks missing (345 of them) have no row. Through 1999 it is identical to the Federal Reserve's H.10 rate on every shared day, and since 2020 it falls between SBI's TT buy and TT sell on 1,448 of 1,460 shared days.
- **India CPI from the IMF is published** at `v1/inflation/in-cpi-imf.csv`: monthly from 1957-01, on the IMF's 2024 = 100 base, with every value exactly as the IMF prints it (some carry sixteen significant digits). It equals MoSPI's index from 2025 except July 2026, a MoSPI revision the IMF has not taken up yet, and is within 0.44% of MoSPI's back series for 2013-2024.
- **SDMX source**: one module reads both agencies' SDMX APIs as CSV, configured per dataset by provider, dataflow, version and series key. A period that is empty, `NaN` or flagged missing is an absent row; any other value that does not parse fails the run; a later fetch revises an earlier one. The BIS series fetches in full on its first run and the last 60 days afterwards; the IMF series is small enough to fetch whole, and an unchanged response is not archived again.
- **MoSPI CPI source**: fetches the full history on its first run and the live series' last two years afterwards; refuses an index that is not a decimal string, rows the filters should have excluded, or another base year.
- **`v1/metadata.json`**, describing every published series: columns, source, licence, rows, range, sha256 and when its content last changed.
- **The site at `data.xfina.dev`**: an assets-only Cloudflare Worker serving the CSVs, metadata and manifests with open CORS. The index lists datasets under headings set by each one's `preview.group` (USD/INR Rates, Inflation), marks any not yet published, and gives developers the CSV URLs and `metadata.json`; each published dataset has a preview page at `/datasets/<id>/` with a Chart / Calendar toggle, range presets and a CSV download, laid out like xfina.dev: the same header (logo, title, sakthipriyan.com and GitHub links, a light/dark toggle that remembers the choice), the same zinc theme, buttons and cards.
- **Per-dataset previews, configured in the catalog**: a `preview` block names the group, the summary, unit, which columns to draw with their labels, and optional extra views. A published dataset must have one, so a series can be seen before anyone builds on it. Tooltips and calendar cells show each value's published text exactly. Computed views — CPI's year-on-year change, day-on-day and month-on-month changes — are drawn in the browser, labelled as computed, and never written to a file. The two chart colours are validated for colour-blind separation in light and dark mode.
- **Calendar view**: a daily series shows a year, or a decade of yearly strips newest first, as a GitHub-style grid of days, coloured by the change on the previous published day (blue fell, red rose, grey unchanged) or by level. A day with no published value is an empty outline, so weekends, holidays and gaps are visible rather than hidden. A monthly series shows every year as a row of twelve cells carrying the published value, coloured month-on-month, year-on-year or by level. Change scales are symmetric about zero and clipped at the 95th percentile, so one outlier does not wash out the rest.
- **Workflows**: `Sync` runs at 16:00 and 22:00 IST and on merges to `main`, commits to the `data` branch, deploys, and opens a `sync-failure` issue when anything fails. `Import Raw` imports an existing archive from a public repository at a pinned commit.
- **Invariant**: no published value may be zero or negative.

- **Repository skeleton:** a Cargo workspace holding the `xfina-data` binary and an `xtask` package, with the workspace version as the single source of truth, `cargo xtask` wired through `.cargo/config.toml`, and `AGENTS.md` carrying the project's rules.
- **CLI surface:** `sync`, `backfill`, `raw put`, `raw import`, `reconcile`, `config validate` and `site build`, parsed with clap. Every subcommand currently fails with "not implemented yet" rather than doing nothing quietly, so a half-wired pipeline cannot look like a successful run.
- **Dataset catalog:** `datasets.yaml` describes every dataset — its source, frequency, licence, raw prefix and the path and columns it publishes. `xfina-data config validate` checks it, reporting every problem at once rather than one per CI round trip, and refuses a catalog that needs a newer tool than the binary running it.
- **Published contract check:** a dataset marked `status: published` has its path, columns and frequency frozen. `config validate --base <file>` fails a pull request that moves or removes one, because people we cannot see have written code against those URLs. A `planned` dataset stays free to change, which is what makes it safe to describe a series before it exists.
- **Series core:** a sorted, de-duplicated map from period to row, keyed by a day or a calendar month — never both in one series. Merging reports every row it added or changed, so a value being silently rewritten is not possible. Invariants cover row width, key consistency and missing months; daily gaps are left alone, since weekends are gaps.
- **CSV read and write** that round-trip exactly, preserving the source's precision: a rate published as `90.50` is written back as `90.50`, not `90.5`. Reading refuses a blank cell by name rather than coercing it — the predecessor coerced blanks to `0.0` and published 54 of them as real rates.
- **CI:** `Check PR` runs `cargo fmt --check`, `cargo clippy -D warnings` and `cargo test`, skips the build when only documentation changed, and requires a changelog entry for any change a consumer of the published data could observe. It also validates the catalog against the one on the base branch.
